# Dhanush R. Portfolio

A responsive personal portfolio for Dhanush R., built with React, TypeScript, Vite, React Three Fiber, Drei, Framer Motion, and Lucide.

## Run locally

```bash
npm install
npm run dev
```

Vite will print the local URL (normally `http://localhost:5173`).

## Quality checks

```bash
npm run lint
npm run build
```

## Deploy to Vercel

1. Create a new GitHub repository and push this project.
2. Import that repository in the Vercel dashboard.
3. Keep the detected Vite build settings: `npm run build` and output directory `dist`.
4. Deploy. To add a custom domain later, open the deployed Vercel project’s **Domains** settings and follow its DNS verification instructions.
